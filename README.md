# aed
긴급 재설정 명령어 모음

`./status` 명령으로 시간 동기화와 네트워크 설정 상태를 확인한다.
`./run` 명령으로 네트워크 설정과 시간 동기화를 복구한다. 관리자 권한은 자동으로 요청한다.

네트워크는 NetworkManager 기준이다. 저장된 유선·무선 연결 중 IPv4 설정이
`manual`인 프로필을 `auto`로 전환한다. 수동 주소, 게이트웨이, DNS, 검색 도메인,
경로를 지우고 DHCP 제공 DNS 및 경로를 사용하도록 설정한다.
IPv4 설정이 이미 `auto`인 프로필도 수동 DNS, 검색 도메인, DNS 옵션과 우선순위를
기본값으로 되돌리고 DHCP 제공 DNS 사용을 활성화한다. 이 경우 주소와 경로는 유지한다.
활성 연결은 다시 활성화하며, 비활성 프로필은 저장된 설정만 변경한다.
다른 IPv4 방식과 IPv6 설정은 유지한다. 연결을 다시 활성화하면 IP 주소가 바뀌거나
원격 접속이 끊길 수 있다. 네트워크 복구 실패 시 시간 복구는 실행하지 않는다.

필수 도구는 `nmcli`, `systemctl`, `timedatectl`이며, 시간 동기화에는
systemd-timesyncd 서비스를 사용한다. 시간대와 동기화 대기 시간은
`aed.conf` 파일에서 설정한다.
